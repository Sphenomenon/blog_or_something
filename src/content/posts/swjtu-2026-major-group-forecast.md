## 结论

先说判断。2026如果交大四川物理类改成更清楚的专业组，价格不会整体一起涨。更可能是：电气、电子、计算机这类高偏好专业修复折价；土木、材料、生医这类低偏好专业失去热门专业遮盖；交运介于中间，品牌强，但仍要看组内有没有低偏好专业。

| 方向 | 2025基准 | 2026中性估计 | 判断 |
| --- | --- | --- | --- |
| 电气工程 | 628 / 9704 | 631-634 / 7600-8800 | 小涨，空间有限 |
| 电子信息 | 630 / 8961 | 631-635 / 7200-8800 | 小涨，和电气同层 |
| 计算机/智能 | 617 / 14292 | 624-628 / 9800-12000 | 修复混装折价 |
| 交通运输 | 610 / 17774 | 607-614 / 15700-19300 | 大概率不涨，强包装才稳住 |
| 土木/智能建造 | 614 / 15739 | 600-607 / 19300-23000 | 单独成组后承压 |
| 材料/生医 | 605-607 / 19363-20484 | 596-604 / 20500-25500 | 冷端暴露，可能下探 |

这张表按位次估，分数只是翻译。2026一分一段和专业组清单没出来前，不给单点预测。

## 样本

我只用普通类同专业或近专业簇，排除中外合作、民族班、专项、定向、预科、艺体。学校最低线不拿来冒充专业线。

| 样本 | 对照 | 观察 |
| --- | --- | --- |
| 交大计算机 | 2024四川理科633/9672；2025四川物理617/14292，均分625.05 | 2025最低线像混装折价，不像真实需求中心 |
| 交大电气 | 2025四川物理628/9704 | 已经接近强211高位，继续涨会碰985低位组 |
| 交大电子信息 | 2025四川物理630/8961 | 交大最高需求层之一 |
| 西华电气 | 2024约584/37911；2025为590/30107 | 清晰强势专业能前移 |
| 江南食品 | 2024约1.7万位；2025为625/15100 | 冷门王牌也能靠专业实力托住 |
| 江南食品AI班 | 2024约1.1万位；2025为637/8838 | “冷专业+AI包装”明显改善 |
| 东莞理工计算机 | 独立组后长期维持在约6万位上下 | 热专业单列后价格更稳定 |
| 深圳大学2024-2025 | 广东、湖南、湖北专业级数据 | 计算机、AI、电子信息维持强需求 |

这些样本给出的方向很清楚：分组变干净以后，热专业会减少折价；冷专业不会自动吃到学校名气红利。要判断土木、材料、交运，不能靠“交大牌子强”这种直觉，得看拆组后这个专业自己能不能卖得动。

## 算法

核心变量是位次变化。这里不用裸分做回归，用位次增益 `G`：

```text
G_i = -ln(R_i,2026 / R_i,base)

R_i,2026 = R_i,base * exp(-G_i)
```

`R` 是最低录取位次。`G > 0` 表示位次前移，`G < 0` 表示位次后退。裸分只在最后用四川一分一段近似换算。

我的估计式是：

```text
G_i = A_i
    + M_i
    + C_i * D_i
    - E_i
    - T_i
    - N_i
    + P_i
```

变量取值用区间，不装成精确系数：

| 项 | 含义 | 取值 |
| --- | --- | --- |
| `A_i` | 历史锚修正。同校同专业越稳定，越接近0 | -0.03 到 +0.03 |
| `M_i` | 年份市场热度。2026整体报考风向未知，只给小范围 | -0.04 到 +0.04 |
| `C_i` | 专业组清洁度改善 | 0 清洁无变化；0.04 轻度；0.08 重度 |
| `D_i` | 专业需求强度 | 热门1.0；中性0.4；冷门0.0-0.1 |
| `E_i` | 冷专业暴露惩罚 | 交运0.02-0.06；土木0.08-0.14；材料/生医0.10-0.16 |
| `T_i` | 985/强211天花板惩罚 | 620以下约0；620-625为0.01-0.03；625-635为0.03-0.08 |
| `N_i` | 高分段非线性阻力 | 590-610为0.01；610-625为0.02-0.04；625-635为0.05-0.08 |
| `P_i` | 招生计划修正 | 扩招为负，缩招为正，常规范围-0.05到+0.05 |

分数段阻力单独列出来，因为这是最容易被低估的地方：

| 分段 | `N_i`建议值 | 解释 |
| --- | --- | --- |
| 550-590 | 0-0.01 | 考生密度和机会成本都低 |
| 590-610 | 0.01-0.02 | 普通强校热门专业开始拥挤 |
| 610-625 | 0.02-0.04 | 211强专业、弱985边缘开始互相挤压 |
| 625-635 | 0.05-0.08 | 普通985低位组形成明显天花板 |
| 635-650 | 0.08-0.12 | 再涨需要强专业确定性或明显缩招 |
| 650+ | 0.12以上 | 进入另一档竞争池 |

算法步骤：

1. 找同专业历史位次，优先用本校本省，其次用同层学校同专业。
2. 标记专业组污染：清洁、轻度混装、重度混装。
3. 给专业偏好打方向：电气、电子、计算机为正；土木、材料、生医为负；交运中性偏弱。
4. 对重度混装样本做折价修正。计算机的2025最低分只作下沿，不作中心。
5. 加入625-630附近的985软天花板。川大、重大普通低位组会限制交大热门专业上沿。
6. 按分段阻力把位次变化翻译成分数区间。

三个示例：

```text
计算机/智能组：
R_base = 14292
G = A(0.03) + M(0.00) + C(0.08)*D(1.00) - E(0.00) - T(0.02) - N(0.03) + P(0.02)
  = 0.08
R_2026 = 14292 * exp(-0.08) ≈ 13193

如果把2024同专业9672位也作为上沿锚，综合区间约为9800-12000位。

交通运输组：
R_base = 17774
G = A(0.00) + M(0.00) + C(0.04)*D(0.40) - E(0.04) - T(0.00) - N(0.02) + P(0.00)
  = -0.044
R_2026 = 17774 * exp(0.044) ≈ 18574

所以中性判断按15700-19300位震荡处理，不按上涨处理。

材料/生医组：
R_base = 20000
G = A(0.00) + M(0.00) + C(0.04)*D(0.10) - E(0.13) - T(0.00) - N(0.01) + P(0.00)
  = -0.136
R_2026 = 20000 * exp(0.136) ≈ 22914

这就是材料/生医中性区间下探到约20500-25500位的原因。
```

## 计算机

计算机最容易看错。2025最低617/14292，比2024的633/9672低很多；但2025均分还有625.05。同年电子信息630/8961，电气628/9704。这个组合不支持“交大计算机没人要”。

我的读法：2025考生买到的是一个带调剂风险的包，末位考生给这个风险打了折。2026如果计算机、软件、AI之类单独成组，且保专业规则更清楚，折价会收窄。中性区间放在624-628；如果仍混入明显低偏好专业，就看620-624。

## 冷组

我同意土木、材料、交运不能凭感觉写成上涨。拆组以后，冷专业会失去热门专业流量。可比样本里真正上涨的，是西华电气、江南食品AI、深圳计算机/AI/电子这类“专业本身有需求”或“包装后需求改善”的方向。土木、材料、生医不满足这个条件。

交运比土木和材料强，因为交大轨交标签确实有用。但它的买方也不同于电气、电子、计算机。若交通运输组里混入低偏好方向，价格会往610以下压；若组内足够纯，且强调轨道交通主线，才可能守在610-614附近。

| 冷组 | 下行理由 | 托底因素 |
| --- | --- | --- |
| 交通运输 | 就业想象弱于电计，组内若不纯会被折价 | 交大轨交品牌 |
| 土木/智能建造 | 行业预期弱，单列后不再被热门组遮盖 | 智能建造、双学位包装 |
| 材料/生医 | 专业偏好弱，考生规避明显 | 若计划少或和较热工科绑定，可止跌 |
